# Leviathan Level 0 → 1

## What I did

After logging in as `leviathan0`, I started by checking what files were available in the home directory.

```bash
ls -la
```

I found a file called `bookmarks.html`.

I wasn't sure if it was important, but I decided to take a look at it anyway.

```bash
nano bookmarks.html
```

While scrolling through the file, I found the password for `leviathan1`.

And that's basically it for this level.

## What I learned

- Always check the files in the home directory.
- Don't ignore files just because they look normal.
- Sometimes the solution is much simpler than expected.

This level was pretty easy, but it reminded me that enumeration is important. You never know what information might be hiding in an ordinary file.
